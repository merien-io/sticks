Burn the bundler.
Drop in the binary.

Modern web development is a landfill of transpilers, JSON glue APIs, and transitive dependencies. Sticks is an opinionated, zero-build, server-rendered web platform packaged as a single static Rust binary.

Read the Manifesto on GitHub See the Syntax ↓

Strict Execution Zones

Execution flows strictly top-to-bottom. Mutations and redirects live in the Effect Zone. Once the first byte of HTML is streamed, you are in the View Zone. Side effects are structurally forbidden.

Injection is Impossible

SQL queries must be string literals. No dynamic concatenation allowed. Output is escaped by default according to its type. Template re-scanning is impossible. Data is inert.

Rule S4: No Nesting

Blocks cannot nest inside other blocks. Deep UI branching is solved cleanly via sibling blocks, component composition, or client-side CSS state projection. Deal with it.

Drop-in simplicity.
Zero parsing conflicts.

The runtime engine never parses your HTML. It scans for || and |, and ignores absolutely everything else.

Because of this, you can drop any client-side framework (like Alpine.js or Tailwind) straight into your code. No escaping curly braces. No delimiter collisions. If you need a literal `$` inside a Sticks block, just write `$$`.
